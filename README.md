# Exercícios de Lógica com Python

Repositório para praticar lógica de programação e aprender Python por meio de exercícios. A ideia é registrar a evolução do aprendizado, desde conceitos básicos até problemas mais elaborados.

## Objetivos

- Praticar a resolução de problemas passo a passo.
- Aprender a sintaxe e os recursos fundamentais do Python.
- Desenvolver o hábito de escrever, executar e revisar código.


## Como executar

1. Instale o [Python 3](https://www.python.org/downloads/), caso ainda não esteja instalado.
2. Clone o repositório e entre na pasta do projeto:

   ```bash
   git clone https://github.com/pauloqueirozz01/exercicio-logica-com-python
   cd exercicio-logica-com-python

   ```

3. Execute o arquivo inicial:

   ```bash
   python3 index.py
   ```

> No momento, o comando não produz saída porque `index.py` ainda não contém código.

## Sugestões de temas para praticar

- Variáveis, tipos de dados e operadores.
- Condicionais e estruturas de repetição.
- Listas, tuplas e dicionários.
- Funções e resolução de problemas.
